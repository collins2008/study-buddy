## 1. Core Concepts & Definitions
- **Information Technology (IT)**: Uses computers, software, networks, and related systems to create, process, store, secure, and exchange information across individuals and organisations.
- **Data**: Raw, unprocessed, unorganised facts, figures, symbols, or observations that lack context (e.g., "38, 42, 19").
- **Information**: Data that has been processed, organised, structured, or contextualised to be meaningful and useful for human decision-making (e.g., "Average test score: 33%").
- **Computer**: An electronic device operating under the control of instructions stored in its own memory that accepts data (input), processes it according to specified rules, produces results (output), and stores the results for future use. Strictly requires electricity/electrical energy to operate.
- **The Three Foundational Building Blocks of IT**:
  1. *Hardware*: Physical equipment and electronic circuitry.
  2. *Software*: Non-tangible programs, scripts, and instructions that tell hardware what to do.
  3. *People / Users / IT Professionals*: The human element who design, administer, input data, and make decisions based on system outputs.
- **Computer vs Network vs Internet**:
  - *Computer*: Standalone computing device performing input, processing, output, and storage.
  - *Network*: Two or more interconnected computers sharing resources (printers, files) and communicating via protocols.
  - *Internet*: A global "network of networks" linking millions of private, public, academic, business, and government networks using the TCP/IP protocol suite.
- **Networks vs Networking vs Networkers**:
  - *Networks*: The physical and logical infrastructure of connected devices.
  - *Networking*: The practice and process of linking computers and configuring communication protocols.
  - *Networkers*: The human professionals, administrators, and engineers who design, manage, and maintain network infrastructure.

## 2. Information Processing Cycle & Processing Paradigms
- **Four Core Stages of Information Processing Cycle**:
  1. *Input*: Capturing or entering raw data into the computer system (keyboard, sensor, scanner, barcode reader).
  2. *Processing*: Manipulating, computing, sorting, or validating data according to instructions (executed by CPU).
  3. *Output*: Presenting processed information in human-readable or usable form (monitor, printer, speaker).
  4. *Storage*: Retaining data and information permanently or semi-permanently for future retrieval (SSD, HDD, Cloud).
  *(Feedback: Evaluating output to refine input/processing in control systems).*
- **Data Processing Methods**:
  - *Batch Processing*: Collecting transactions over a period and processing them together as a batch at a scheduled time (e.g., monthly payroll calculation, end-of-semester university GPA generation). Advantage: highly efficient computer utilization during off-peak hours.
  - *Real-time / Online Transaction Processing (OLTP)*: Processing transactions immediately as they occur (e.g., ATM withdrawals, flight bookings, mobile banking transfers). Advantage: immediate updating and prevents double-spending/booking.

## 3. Data Representation & Data Quality Dimensions
- **Bit (Binary Digit)**: The fundamental, smallest unit of digital data ($0$ or $1$, representing off/on switch voltage states).
- **Byte**: Exactly 8 bits grouped together ($2^8 = 256$ possible distinct bit patterns, sufficient to represent a single character in ASCII).
- **Nibble**: A 4-bit group ($2^4 = 16$ values, exactly one hexadecimal digit).
- **Data Quality Dimensions**:
  - *Accuracy*: Data correctly represents the real-world event or value without errors.
  - *Completeness*: All required data fields are recorded with no missing values.
  - *Consistency*: Data across different databases or systems matches without contradictions.
  - *Timeliness / Currency*: Data is up-to-date and available when needed for decision-making.
  - *Relevance*: Data serves the specific purpose required by decision-makers.
- **Data Validation vs Verification**:
  - *Validation*: Automated system checks ensuring input conforms to predefined business rules and formats (e.g., range check, format check, presence check).
  - *Verification*: Confirmation that entered data matches the authentic original source document (e.g., double data entry, visual inspection).

## 4. Hardware Categories at a Glance
1. *Input Devices*: Keyboard, mouse, touchscreen, document scanner, microphone.
2. *Processing Devices*: Central Processing Unit (CPU), Graphics Processing Unit (GPU).
3. *Storage Devices*: Solid-state drives (SSD), Hard disk drives (HDD), USB flash drives.
4. *Output Devices*: Display monitors, printers, audio speakers, video projectors.
5. *Communication Devices*: Network Interface Cards (NIC), modems, wireless routers, switches.
