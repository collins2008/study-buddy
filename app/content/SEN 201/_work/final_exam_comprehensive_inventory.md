## 2. Exhaustive Concept Inventory

### A. The Complete Software Engineering Lifecycle
- Engineering vs Craft: Applying systematic, disciplined, quantifiable approaches to development, operation, and maintenance.
- Phase Progression: Feasibility Study -> Requirements Elicitation & Specification -> Architectural & System Design -> Implementation & Unit Testing -> Integration & System Testing -> Acceptance & Deployment -> Operation & Evolution.

### B. Natural Language vs Structured Specifications
- Flaws of Pure Natural Language: Semantic ambiguity, lack of modularity, contradiction between stakeholder interpretations.
- Structured Alternatives: User stories with acceptance criteria, formal specifications, tabular specs, graphical UML models.

### C. Prototyping in Software Engineering
- Throwaway Prototyping: Built to clarify requirements and explore design alternatives, then discarded.
- Evolutionary Prototyping: Built to explore requirements, but continuously refined into the final production system.

### D. Open Source & Commercial Software Ecosystems
- Open-Source Licenses: Permissive (MIT, Apache 2.0) vs Copyleft (GPL).
- Commercialization Strategies: Dual licensing, support & professional services, managed cloud hosting (Open Core model).

### E. Holistic System Quality & Trade-offs
- Balancing Functional Requirements against Non-Functional Constraints (Security, Performance, Availability, Maintainability).
- Technical Debt Management: Refactoring, test automation, continuous integration.
