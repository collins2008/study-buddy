## 4. Key Conceptual Domains Verified

1. **Software Process Models**:
   - Waterfall (strict linear sequential gates, high late-stage risk).
   - Boehm's Spiral (four quadrants: Objective, Risk Analysis, Engineering, Review).
   - Kruchten's RUP (Inception, Elaboration, Construction, Transition).
   - Agile/Scrum (3 roles, 5 events, 3 artifacts; 2-4 week sprints).
   - Extreme Programming (XP) (Pair Programming, TDD, CI, Refactoring).
   - Kanban (continuous workflow, WIP limits, bottleneck elimination).
2. **Requirements Engineering**:
   - Functional vs Non-Functional requirements (quantifiable quality benchmarks).
   - Elicitation, Analysis, Specification (IEEE 830 / ISO 29148 SRS), Validation.
   - Requirements Traceability Matrix (RTM) and Change Control Boards (CCB).
3. **UML 2.5 Object-Oriented Modeling**:
   - Structural: Class diagrams, Aggregation (open diamond, shared ownership) vs Composition (filled diamond, lifecycle death-dependency).
   - Behavioral: Use Cases (`<<include>>` mandatory vs `<<extend>>` conditional), Sequence Diagrams (lifelines, synchronous vs asynchronous calls), Activity Diagrams (swimlanes, fork/join concurrency).
4. **Testing & Quality Assurance**:
   - Black-box: Equivalence Partitioning, Boundary Value Analysis (min, min-1, nominal, max, max+1).
   - White-box: Statement, Branch, and Cyclomatic Complexity ($V(G) = E - N + 2P$).
   - Verification ("Are we building the product right?") vs Validation ("Are we building the right product?").
