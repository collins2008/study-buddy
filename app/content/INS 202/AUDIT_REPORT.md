## 4. Key Conceptual Domains Verified

1. **HCI Foundational Goals**:
   - Safety (physical protection and data preservation), Utility (functional capabilities), Effectiveness (successful task completion), Efficiency (speed and cognitive workload), Usability (learnability, memorability, error recovery).
   - Interaction (abstract behavioral dialogue) vs Interface (concrete physical/GUI widgets).
2. **Cognitive Psychology & Ergonomics**:
   - George Miller's Law: $7 \pm 2$ chunks in short-term working memory; chunking strategy.
   - Recognition over Recall: Visual browsing reduces cognitive friction compared to memorized command recall.
   - Gestalt Principles: Proximity, Similarity, Continuity, Closure, Symmetry.
   - Fitts's Law: $T = a + b \log_2(1 + D/W)$. Screen corners and borders possess infinite virtual width ($W=\infty$).
   - Hick-Hyman Law: $T = b \log_2(n + 1)$ (logarithmic decision time).
   - Robert Miller's Response Time Thresholds: $0.1\text{s}$ (instantaneous direct manipulation), $1.0\text{s}$ (uninterrupted flow), $10\text{s}$ (attention limit; requires progress bar).
3. **User-Centered Design (UCD) & Prototyping**:
   - Core principle: "Know thy user." Designers $\ne$ Users.
   - Prototyping Fidelities: Low-fidelity (paper, rapid, low-attachment) vs High-fidelity (interactive, design system).
   - Horizontal (broad breadth, shallow depth) vs Vertical (narrow breadth, full architectural depth).
   - Think-Aloud Protocol for usability testing without evaluator coaching.
4. **Usability Evaluation & Accessibility**:
   - Performance (objective: task time, error count) vs Preference (subjective: Likert scale agreement).
   - System Usability Scale (SUS): 10-item Likert survey scored 0-100; benchmark 68 is average.
   - Nielsen's Heuristic Evaluation: 3 to 5 independent evaluators discover 75-85% of usability defects.
   - W3C WCAG 2.1 POUR: Perceivable, Operable, Understandable, Robust. ARIA roles and landmarks.
