6. Navigation Design
In this module you will learn about:
Site-level navigation: making it easy for the user to get around the site
Page-level navigation: making it easy for the user to find things on a page
=== SLIDE 3 ===
Site-level vs. Page-level Navigation
Site-level navigation encompasses issues pertaining to understanding and moving through the information architecture of a Web site. 
Page-level navigation includes techniques that enhance the comprehensibility of an individual Web page.

Navigation Systems cont.
A hierarchical navigational: provides users with a top-down view of a site. 
Ad hoc systems serve a hypertext organizational structure and typically appear as embedded links in a Web page. 
A database navigational system implements a database organizational structure. A user types in a word or phrase to find related pages.

=== SLIDE 9 ===
Global navigation system
Navigation bar: A navigation bar is a list of links grouped together on a page. 
Global navigation system: Such a system appears consistently on every page of the site and offers navigation options for the entire site. For small sites such as a personal site, a global navigation system is sufficient.

=== SLIDE 12 ===
Other page levels & Breadcrumbs
Secondary pages are reachable from the home page by one click. A third-level page is one click away from a secondary page.
Breadcrumbs display a record of links that the user clicked in the process of traveling to the current page. They are a record of a user’s trail through the site. In a sense, they serve as a sign that reads, “You are here,” and thus help build context for a user. 
They are useful in sites having three levels or more.

=== SLIDE 15 ===
Subsites…
A subsite is a collection of pages within a web site that can share a common navigation system, which may be different in style from the Web site as a whole. 
A local navigation system helps users with accessing a subsite and complements the site’s global navigation.

=== SLIDE 17 ===
Ad hoc Links
Ad hoc links express relationships among content items that cannot be accommodated by a hierarchical system. 
They usually appear as embedded links on a page. They add flexibility that is lacking in a pure hierarchical system. 
When adding ad hoc links try positioning them in a bulleted list or place them at the start or the close of a paragraph so that they stand out enough that users can see them while scanning the page.

Navigational Elements
Navigational elements are visual organizations of text and graphics that display a user’s options and current position in a site. 
The most common of these are navigation bars and menus. 
Others include: site maps and frames.

Graphical vs Text Navigation Bars
Graphical navigation bars have enormous appeal. They can also display context (“You are here”) clearly. However, they take longer to download than text. 
Also, if a user has turned off image loading, he or she may not be able to see the navigation bar at all. 
Graphical navigation bars are more costly to maintain than text-based navigation bars because they require access to additional graphics software and additional graphics expertise to change them

=== SLIDE 30 ===
Menus
Menus present a list of possible links in the form of a drop-down or scrollable list. 
The biggest difference in appearance when compared to a navigation bar is that all of the items in the various menus are not visible at any one time.
06: Navigation
Copyright © 2004 by Prentice Hall
=== SLIDE 31 ===
Menus: Advantages and Disadvantages
With menus, it’s possible to pack a lot of options onto a single page, minimizing the number of clicks required to reach a particular page. 
This reduces the number of page downloads, which is always a plus. 
However, some experts believe that menus carry two disadvantages. 
With menus, not all options are visible at any one time.
Further, a user must act before seeing: a user must scrub the cursor over an item in order to activate the list.
