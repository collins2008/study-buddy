What is software?
Software is a set of programs and instructions that tell a computer what to do.
CO2 • SOFTWARE & OPERATING SYSTEMS
03
Software gives hardware useful tasks and rules to follow.
It includes operating systems, applications, utilities, drivers and firmware.
Software may be installed locally or delivered through a browser or cloud service.
Software needs updates and maintenance over time.
EXAMPLE
A laptop has hardware components, but a word processor is software used to create a report.

=== SLIDE 4 ===
What is an operating system?
An operating system (OS) manages computer resources and provides services to programs.
CO2 • SOFTWARE & OPERATING SYSTEMS
05
It manages CPU time, memory, storage and connected devices.
It provides a user interface and file-management tools.
It controls access to resources and supports security features.
It helps applications run without each application controlling hardware directly.
EXAMPLE
Windows, macOS, Linux, Android and iOS are operating systems.

CO2 • SOFTWARE & OPERATING SYSTEMS

=== SLIDE 8 ===
Files and folders
Files store named collections of data; folders organise them.
CO2 • SOFTWARE & OPERATING SYSTEMS
09
Files may contain text, images, video, programs or structured data.
Folders/directories group related files in a hierarchy.

CO2 • SOFTWARE & OPERATING SYSTEMS
10

File paths and organisation
A file path identifies where a file is located.
CO2 • SOFTWARE & OPERATING SYSTEMS
11
An absolute path starts from a system's root or drive location.
A relative path is interpreted from a current folder or project location.

Be careful when moving files that linked applications depend on.

=== SLIDE 11 ===
File permissions and sharing
Permissions help control who can view or change files.
CO2 • SOFTWARE & OPERATING SYSTEMS
12
Read permission allows viewing; write permission allows modification.
Execute permission may allow a program or script to run.
Sharing links can grant access to specific people or anyone with the link.
Use the least access needed and review permissions periodically.
Avoid sharing sensitive files through public links.
SCENARIO
A student should share a draft with the supervisor rather than make private research data public.

=== SLIDE 17 ===
Licensing: proprietary, open-source and freeware
A licence defines how software may be used, changed and shared.
CO2 • SOFTWARE & OPERATING SYSTEMS
18
Proprietary software is controlled by its owner under licence terms.
Open-source software makes source code available under a licence with defined rights and obligations.
Freeware is available at no monetary cost, but may still be proprietary.

Software troubleshooting
A systematic process helps isolate software problems.
CO2 • SOFTWARE & OPERATING SYSTEMS
24

Check whether the problem affects one file, one application or the whole system.
Restart the application or device when safe and appropriate.
Check updates, permissions, storage space and compatibility.
