Why computers use binary
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
4
Digital computers use electronic circuits with two reliable states.
These states are commonly represented as 0 and 1.
A binary digit is called a bit (short for binary digit).
At the hardware level, 0 and 1 can correspond to low/high voltage or off/on states.
Binary is not the only way humans write numbers; it is the practical language used by digital hardware.

KEY TAKEAWAY

=== SLIDE 5 ===
DATA REPRESENTATION & PROCESSING
Bits: the smallest unit
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
5
A bit is the smallest unit of digital information.
A bit can hold one of two values: 0 or 1.
One bit alone can represent only two possibilities, such as yes/no or true/false.
More bits allow more combinations: 2 bits = 4 combinations; 3 bits = 8 combinations.
With n bits, the number of possible patterns is 2ⁿ.
1 BIT
2 possible patterns: 0 or 1.
3 BITS
8 patterns: 000 to 111.
KEY TAKEAWAY
The number of possible patterns doubles whenever one extra bit is added.

6
A byte is a group of 8 bits.
A byte can represent 256 different patterns (2⁸), from 00000000 to 11111111.
Text characters, small numeric values and parts of files can be encoded using bytes.
Computers group bytes into larger units to measure memory and file sizes.
Example: a short text file may occupy a few kilobytes; a video may occupy gigabytes.

=== SLIDE 7 ===
DATA REPRESENTATION & PROCESSING
Understanding binary place value
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
7
Binary is a base-2 number system; it uses only 0 and 1.
Each position represents a power of 2, moving from right to left.
Example: 1011₂ = (1×8) + (0×4) + (1×2) + (1×1) = 11₁₀.
The subscript ₂ identifies binary; the subscript ₁₀ identifies decimal.
Computers use binary internally, while users commonly enter decimal numbers.

4
2²
2
2¹
1
2⁰
KEY TAKEAWAY
Binary place values increase by powers of two from right to left.
=== SLIDE 8 ===
DATA REPRESENTATION & PROCESSING
Worked example: convert binary to decimal
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
8
Convert 1101₂ to decimal.
Write the place values: 8, 4, 2, 1.
Multiply each bit by its place value: (1×8) + (1×4) + (0×2) + (1×1).
Add the results: 8 + 4 + 0 + 1 = 13.
Therefore, 1101₂ = 13₁₀.
KEY TAKEAWAY
Only add the place values where the binary digit is 1.

Storage units: from bytes to terabytes
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
20
Digital storage capacity is measured in bytes and larger multiples.
Common decimal units: 1 KB = 1,000 bytes; 1 MB = 1,000 KB; 1 GB = 1,000 MB; 1 TB = 1,000 GB.

Manufacturers often advertise decimal capacity, while some operating systems display binary-based values.
Always check whether a figure uses decimal or binary units when comparing capacities.

INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
40
An SSD stores data in flash memory chips and has no moving mechanical parts.
SSDs generally provide faster boot times, application loading and file access than HDDs.
They are quieter, use less power in many cases and resist ordinary movement better.
SSDs usually cost more per gigabyte than HDDs, although prices continue to change.
Example: a laptop with an SSD often starts faster and feels more responsive.
ADVANTAGE
Fast access and no moving parts.
LIMITATION
Cost per GB may be higher than an HDD.
KEY TAKEAWAY
SSDs are a strong choice for operating systems and frequently used applications.

A backup is a separate copy of data that can be used to restore information after loss or damage.
Backups protect against accidental deletion, device failure, ransomware, theft and disasters.
A backup should be separate from the original data; simply copying a file to another folder on the same drive is not enough.
Backups should be scheduled, monitored and tested through restore exercises.
Example: a lecturer backs up lecture slides and student marks to an encrypted external drive and a secure cloud location.

KEY TAKEAWAY

=== SLIDE 35 ===
STORAGE AND CLOUD SERVICES
Backup types: full, incremental and differential
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
45
Full backup: copies all selected data each time; simplest to restore but can require more time and space.
Incremental backup: copies data changed since the most recent backup of any type; efficient, but restoration may need several backup sets.
Differential backup: copies data changed since the last full backup; restoration needs the full backup and latest differential.
Organisations combine methods to balance backup speed, storage use and recovery time.
Example: a weekly full backup with daily incremental backups.
FULL
All selected files.
INCREMENTAL
Changes since last backup.
DIFFERENTIAL
Changes since last full backup.
KEY TAKEAWAY
Backup strategy affects both storage requirements and recovery effort.

Example: laptop copy + external drive + secure cloud backup.

STORAGE AND CLOUD SERVICES
Common misconceptions to avoid
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
57
“Cloud means my files are stored in the sky.” In reality, they are stored on physical servers in data centres.
“Sync is backup.” Not necessarily; deletions and unwanted changes can sync too.
“An external drive cannot fail.” All storage devices can fail, be lost or be damaged.
“More storage makes a computer faster.” Capacity and performance are different characteristics.
“Cloud providers handle all security.” Users and organisations still manage accounts, access and data choices.
KEY TAKEAWAY
Use precise terms and understand what each technology actually does.
=== SLIDE 48 ===
STORAGE AND CLOUD SERVICES
Summary: storage and cloud services
INTRODUCTION TO INFORMATION TECHNOLOGY  |  LECTURE NOTES
58
Primary storage (RAM, cache and firmware memory) supports the computer while it operates.
Secondary storage (HDD, SSD, USB and network storage) retains data for long-term use.
HDDs offer economical capacity; SSDs usually offer faster access and better resistance to movement.
Backups support recovery; synchronisation keeps working copies aligned.
Cloud storage provides network-based access and collaboration, but needs security, governance and backup planning.
KEY TAKEAWAY
The safest storage strategy combines appropriate devices, secure access and tested backups.
