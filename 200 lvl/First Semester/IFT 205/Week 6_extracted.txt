Basic components of a network

End devices: laptops, phones, desktops, printers, servers and smart devices.

Network devices: routers, switches, access points, modems and firewalls.

Transmission media: Ethernet cables, fibre-optic cables and wireless radio signals.

Network software: operating systems, drivers, network services and management tools.

Protocols: rules that define how devices address, format, send and receive data.

Shared resources: files, applications, printers, storage and Internet connections.

Common wireless technologies

Wi-Fi connects devices to a local network and often to the Internet through a wireless access point or router.

Bluetooth supports short-range connections for headphones, keyboards, speakers and other accessories.

Mobile networks (3G, 4G and 5G) provide wide-area wireless connectivity through cellular towers and operators.

A hotspot allows a phone or dedicated device to share mobile Internet with nearby devices over Wi-Fi.

Satellite Internet can provide connectivity where terrestrial networks are limited.

Technologies differ in range, speed, coverage, cost, power use and purpose.

How devices connect to the Internet

A laptop or phone connects to a Wi-Fi router or wired network.

The router manages local connections and forwards traffic towards the Internet connection.

A modem or optical network terminal (ONT) provides the access link, depending on the service.

The Internet Service Provider (ISP) connects the customer link to wider Internet networks.

Exact equipment depends on the type of Internet service and the provider's installation.

What affects network performance?

Available bandwidth and the number of users sharing the connection.

Distance from a Wi-Fi access point, walls, interference and physical obstructions.

Network congestion at home, in an organisation or within the service provider's network.

Quality and age of routers, switches, cables, access points and end devices.

Server performance and the size or design of the service being accessed.

Latency, packet loss and unstable connections can affect calls, streaming and online applications.

IP addresses, domain names and DNS

An IP address identifies a device or network interface for communication on an IP network. Example IPv4 format: 
192.168.1.20.

A domain name is a human-readable name used to locate an Internet service. Example: example.com.

DNS (Domain Name System) translates domain names into IP addresses used to reach services.

When a user enters a website name, the device can ask DNS for the corresponding address before connecting to 
the website server.

What is the Internet?

The Internet is a worldwide system of interconnected computer networks that communicate using the Internet 
Protocol (IP) suite.

Its infrastructure includes routers, fibre-optic cables, mobile networks, data centres, servers and undersea cables.

Protocols such as IP, TCP, UDP, DNS, HTTP and HTTPS help devices exchange data.

The Internet supports websites, email, messaging, cloud storage, streaming, online banking and video calls.

The Internet is the underlying network infrastructure; it supports many different services.

Websites, web pages and web servers

A web page is a single document or resource displayed in a browser. It may contain text, images, links, audio or 
video.

A website is a collection of related web pages and resources usually organised under a domain name.

A web server is a computer or software service that stores, processes or delivers website content to users' 
browsers.

Example: a university website may contain separate pages for admissions, programmes, staff, news, contact 
details and student services.

Web browsers and search engines

A web browser is software used to access and display websites.

Examples of browsers: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari and Opera.

A search engine is an online service that helps users find relevant web pages and information.

Examples of search engines: Google Search, Bing and DuckDuckGo.

Search engines discover, index and rank web content in response to user queries.

A browser is the tool used to visit websites; a search engine helps users find them.

Instant messaging and online messaging

One-to-one chat supports direct messages between two people for quick questions, reminders and short updates.

Group messaging allows several participants to share messages, files and announcements in a group or channel.

Organisations use business messaging for customer support, notifications and team coordination.

Examples include WhatsApp, Telegram, Signal, Microsoft Teams chat and Slack. Features and privacy protections 
vary.

Use the right channel: urgent matters may need a call; formal decisions may need email or an approved record.

Video conferencing and online meetings

Video conferencing enables people in different locations to communicate in real time using audio, video, screen 
sharing and chat.

Common features include meeting links, participant controls, screen sharing, captions and chat. Recording 
depends on permission and policy.

Examples include Zoom, Google Meet, Microsoft Teams and Webex.

Requirements include reliable Internet, microphone, speakers or headset and a suitable device. A camera may be 
optional.

Example: a lecturer can teach remote students, share slides and answer questions.

Digital collaboration and cloud tools

Shared documents allow authorised users to edit or comment on the same file.

Cloud storage keeps files on remote servers so users can access them across approved devices.

Project-management tools organise tasks, owners, deadlines and progress.

Team platforms combine chat, meetings, file sharing, calendars and channels.

Version history can help users review or restore earlier changes to a document.

Examples include Microsoft 365, Google Workspace, Dropbox, Trello and Slack.

Online safety, privacy and responsible use

Use strong, unique passwords and multi-factor authentication where available.

Keep operating systems, browsers, routers and security software updated.

Be alert to phishing messages, fake websites, suspicious attachments and impersonation.

Use HTTPS for sensitive transactions, but remember HTTPS alone does not prove a site is trustworthy.

Limit personal information shared online and review privacy and meeting settings.

Use secure Wi-Fi; avoid sensitive transactions on untrusted public networks unless appropriately protected.

Respect copyright, professional conduct, institutional policies and other people's privacy.
