=== SLIDE 3 ===
A simple definition of IT
03
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Information Technology (IT) uses computers, software, networks and related systems to create, process, store, secure and exchange information.
Data are raw facts; information is data organised to be meaningful.
IT supports communication, record keeping, analysis, service delivery and decision-making.
IT includes people and procedures as well as technical equipment.
KEY IDEA
IT turns data into useful information and makes it available to the right people.

=== SLIDE 5 ===
Hardware: what it is
05
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Hardware is the physical equipment in a computing system.
Examples: processor, memory, storage drive, keyboard, screen, printer, router and cables.
Internal hardware sits inside a device; peripheral hardware connects externally or wirelessly.
Hardware needs power and software instructions to perform useful tasks.
KEY IDEA
If it can be physically handled, it is likely hardware.

=== SLIDE 7 ===
Processing: CPU
08
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
The Central Processing Unit (CPU) executes program instructions.
The control unit coordinates operations; the arithmetic-logic unit performs arithmetic and logical comparisons.
Registers hold tiny amounts of data for immediate CPU use.
CPU performance also depends on architecture, core count, clock behaviour, cooling and workload.
KEY IDEA
The CPU is a key processing component, but it is not the whole computer.
=== SLIDE 8 ===
Memory: RAM and ROM
09
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
RAM is working memory for active programs and data; it is typically volatile.
ROM or firmware storage retains essential instructions without normal power; modern devices use several kinds of non-volatile memory.
More RAM can help with multitasking, but does not automatically make every task faster.
Memory is different from long-term storage such as an SSD.
KEY IDEA
RAM is a workbench; storage is the filing cabinet.
=== SLIDE 9 ===
Storage devices
10
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Hard disk drives (HDDs) store data magnetically and often offer high capacity at lower cost.
Solid-state drives (SSDs) use flash memory and usually provide faster access.
USB flash drives and memory cards are portable storage.
Cloud storage keeps data on remote infrastructure accessed over a network.
Backups are separate copies used to recover from loss or damage.
KEY IDEA
Storage retains files when the device is switched off.

KEY IDEA
Output communicates processed results.

12
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY

Software: what it is
14
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Software is the set of programs, instructions and related data used to operate a computer.
Software is not physically touched, although it is stored on physical media.
Programs use hardware resources to perform tasks.
Software can be updated, configured, licensed and sometimes removed.
KEY IDEA
Hardware provides capability; software directs how that capability is used.

=== SLIDE 21 ===
What is a computer network?
22
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
A network is a group of connected devices that can exchange data and share resources.
Devices may connect by cable, Wi-Fi, fibre or other communication technologies.
Networks can support file sharing, printers, communication, cloud services and centralised systems.
A network may be small, such as a home network, or span countries.
KEY IDEA
Networking allows separate devices to work together.
=== SLIDE 22 ===
Network components
23
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
End devices: computers, phones, printers, servers and smart devices.
Network interface: wired Ethernet or wireless adapter.
Switch: connects devices within a local network.
Router: forwards traffic between networks, often connecting a local network to the internet.
Access point: provides Wi-Fi connectivity; modem or ONT may connect to an internet service.
KEY IDEA
Each network component has a different job.

=== SLIDE 28 ===
IP address, domain name and DNS
29
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
An IP address identifies a network interface for communication at the IP layer.
A domain name, such as example.com, is easier for people to remember.
The Domain Name System (DNS) helps translate domain names into records including IP addresses.
DHCP commonly helps devices obtain network settings automatically.
These concepts work together but are not interchangeable.
KEY IDEA
Names are convenient for people; addresses help route network traffic.
=== SLIDE 29 ===
Network performance terms
30
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Bandwidth: the capacity of a connection, often measured in bits per second.
Throughput: the actual rate achieved under real conditions.
Latency: the delay for data to travel between points.
Jitter: variation in packet delay, important for real-time audio and video.
Packet loss: data packets that fail to reach their destination.
KEY IDEA
Video calls need not only bandwidth but also low delay and low packet loss.
=== SLIDE 30 ===
Network security basics
31
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Use strong, unique passwords and multifactor authentication where available.
Keep operating systems, applications and router firmware updated.
Use WPA2-AES or WPA3 for Wi-Fi security where supported.
Avoid entering sensitive information on untrusted networks; use approved secure connections.
Back up important files and report suspicious messages or unusual device behaviour.
KEY IDEA
Security combines technology, safe behaviour and regular maintenance.
=== SLIDE 31 ===
Data privacy and responsible use
32
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Collect only data needed for a legitimate purpose.
Limit access according to role and need.
Explain how personal data will be used and protect it against unauthorised access.
Follow organisational policy and applicable laws.
Do not share passwords, confidential student records or sensitive files casually.
KEY IDEA
Technical access does not automatically mean permission to use data.

=== SLIDE 33 ===
Troubleshooting: start with symptoms
34
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Identify the symptom and ask what changed recently.
Check power, cables, Wi-Fi status and visible error messages.
Determine whether the issue affects one device, one application or many users.
Restart only when appropriate and save work first.
Record the steps taken and escalate persistent or security-related issues.
KEY IDEA
Troubleshoot methodically rather than guessing.
=== SLIDE 34 ===
Example: no internet on a laptop
35
IFT 205 • INTRODUCTION TO INFORMATION TECHNOLOGY
LECTURE SLIDES
Check whether Wi-Fi is enabled and airplane mode is off.
See whether other devices can connect to the same network.
If only one laptop is affected, inspect its adapter, settings and saved network.
If all devices are affected, check the router and service-provider status.
Avoid resetting equipment or changing advanced settings without permission.
KEY IDEA
Isolate the problem: device, local network or internet service.
