4. Understand These Three Terms
A. HTML tag
A tag is the markup written inside angle brackets. Most common HTML elements use an opening tag and a closing tag. For example, <p> is an opening paragraph tag and </p> is a closing paragraph tag. The forward slash (/) indicates the closing tag.
In this example, <p> opens the paragraph, and </p> closes it.
B. HTML element
An element usually consists of an opening tag, the content, and a closing tag. In the example below, the whole line—including the tags and the words—is the paragraph element.
Opening tag: <h1>    |    Content: Welcome to My Website    |    Closing tag: </h1>
C. HTML attribute
An attribute provides extra information about an HTML element. It is normally written inside the opening tag, as a name followed by an equals sign and a value in quotation marks.
Here, href is the attribute name and https://www.example.com is its value. The browser uses href to know where the link should take the user. The words “Visit Example” are the clickable text.
Quick Comparison
Remember: the symbols < and > are called angle brackets. They surround HTML tag names. A closing tag usually has a forward slash / before the tag name.

6. Explanation of Each Part
<!DOCTYPE html> — Tells the browser that the document uses modern HTML (HTML5). It is a declaration, not a normal HTML element.
<html lang="en"> — The root element. It contains the page's HTML. lang="en" identifies English as the page language.
<head> — Starts the head section, which contains information about the page rather than the main visible page content.
<meta charset="UTF-8"> — Sets the character encoding so letters and symbols can be displayed correctly.
<meta name="viewport" content="width=device-width, initial-scale=1.0"> — Helps the page scale properly on phones and other screen sizes.
<title>My First Web Page</title> — Sets the title shown on the browser tab. It is not the main heading inside the page.
</head> — Closes the head section.
<body> — Starts the body. The visible page content, such as headings, paragraphs and links, goes here.
<h1>...</h1> — Creates the main, level-one heading. A page may have multiple headings, but use heading levels in a logical order.
<p>...</p> — Creates a paragraph of text.
<h2>...</h2> — Creates a second-level heading, usually a subsection under the main heading.
<a href="https://www.example.com">...</a> — Creates a hyperlink. The href attribute stores the destination address.
</body> — Closes the visible-content section.
</html> — Closes the root HTML element and marks the end of the document.
