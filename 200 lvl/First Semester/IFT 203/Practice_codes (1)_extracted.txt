2. How to run the code
Open Notepad or Visual Studio Code.
Copy the complete code from Section 1.
Save the file as student-registration.html. In Notepad, choose Save as type: All Files and use the .html extension.
Open the saved file by double-clicking it. It should open in your default web browser.
To make changes, edit the file in your text editor, save it, and refresh the browser.
3. Important file and image setup
For the example image to appear, arrange the files like this:
MyWebsite/
student-registration.html
images/
computer.jpg
Create a folder named images in the same folder as the HTML file. Put a real image named computer.jpg inside it. If you do not have an image, either add one or remove the entire <img> element. The rest of the page will still work.
4. What should work and what will not
Will work locally: headings, paragraphs, navigation links to page sections, lists, table, form controls, and the external HTML documentation link (when internet is available).
Image: will display only if images/computer.jpg exists and the file name matches.
Form: the text fields, dropdown, radio buttons, checkboxes, submit and reset controls will work in the browser. Because this is a front-end demonstration, it does not save registration data to a database.
No CSS: the page uses the browser's default appearance. The table border attribute is included for beginner demonstration only; modern table styling is normally done with CSS.
