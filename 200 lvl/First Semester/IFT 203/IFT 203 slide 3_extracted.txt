=== SLIDE 18 ===
The HTML document skeleton
• A basic document contains doctype, html root, head and body.
• Head contains metadata not normally shown as page content.
• Body contains the content users see.
• Consistent indentation makes structure clear.
HTML SOURCE
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello</h1>
  </body>
</html>

=== SLIDE 19 ===
DOCTYPE: why it is there
• <!DOCTYPE html> tells the browser to use modern HTML standards mode.
• It is a declaration, not an ordinary HTML element.
• Place it at the very beginning.
• It helps avoid legacy quirks mode.
HTML SOURCE
<!DOCTYPE html>
<html lang="en">

HTML headings: h1 to h6
• HTML provides six heading levels: h1 through h6.
• h1 is the highest-level heading; h6 is the lowest.
• Choose levels based on document structure, not size alone.
• Browsers normally show headings in progressively smaller sizes.

<h3>Subtopic</h3>
