=== SLIDE 3 ===
What is CSS?
INTRODUCTION
CSS means Cascading Style Sheets.
CSS controls the appearance and layout of HTML webpages.
HTML provides structure and content; CSS controls presentation.
CSS changes text, backgrounds, spacing, borders and layout.
INTRODUCTION TO WEB TECHNOLOGY  |  CSS PRACTICAL LECTURE

=== SLIDE 4 ===
HTML and CSS Work Together
INTRODUCTION
HTML creates headings, paragraphs, images, links and buttons.
CSS gives those elements their visual appearance.
HTML without CSS can still work, but it usually looks plain.
CSS does not replace HTML; both technologies work together.
HTML: <h1>My Website</h1>
CSS:  h1 { color: blue; }
EXPECTED RESULT
HTML displays a heading;
CSS makes it blue.

HTML FIRST
<!DOCTYPE html> tells the browser to use modern HTML.
<html> contains the whole document.
<head> contains page information and links to resources.
<title> sets the browser-tab title.
<body> contains visible content; <h1> is a main heading and <p> is a paragraph.

=== SLIDE 16 ===
How the Connection Works
CONNECTING FILES
The browser opens index.html first.
It reads the link element in the head section.
It looks for style.css at the path given in href.
It reads CSS rules and applies matching styles to HTML elements.
If the filename or path is wrong, the stylesheet may not load.
index.html  -- link href="style.css" -->  style.css
       Browser reads HTML              Browser loads styles
EXPECTED RESULT
HTML structure + CSS rules
produce the styled webpage.

CSS Syntax: Selector, Property and Value
CSS FUNDAMENTALS
Selector identifies the HTML element to style.
Property identifies what aspect should change.
Value specifies the chosen appearance or setting.
A declaration is a property and value written together.
Curly braces hold the declarations.
h1 {
    color: blue;
    font-size: 32px;
}
EXPECTED RESULT
A blue heading
with a size of 32 pixels.

=== SLIDE 23 ===
Three Common CSS Selectors
CSS FUNDAMENTALS
Element selector: p targets all paragraph elements.
Class selector: .card targets elements with class="card".
ID selector: #header targets the element with id="header".
Class and ID names in HTML must match the CSS selector.
p { color: green; }
.card { padding: 16px; }
#header { background: navy; }

Green paragraph;
padded card;
navy header.

=== SLIDE 30 ===
The CSS Box Model
BOX MODEL
Every HTML element can be understood as a rectangular box.
Content is the text, image or material inside.
Padding is space between content and border.
Border is the line around padding and content.
Margin is space outside the border, separating elements.

=== SLIDE 31 ===
Width, Height, Margin and Padding
BOX MODEL
width sets an element's width; height sets its height.
margin creates space outside an element's border.
padding creates space inside the border, around content.
max-width limits how wide an element can grow.
min-height sets the minimum height.
.card {
  width: 300px;
  min-height: 120px;
  margin: 20px;
  padding: 16px;
}
EXPECTED RESULT
A 300px-wide card
with inside and outside spacing.

border-radius rounds the corners of a box.

=== SLIDE 33 ===
The display Property
LAYOUT
display controls how an element participates in layout.
block starts on a new line and normally takes available width.
inline flows within a line.
inline-block flows inline but can have width and height.
none hides the element; flex and grid activate layout systems.
.notice { display: block; }
.hidden { display: none; }
EXPECTED RESULT
Block elements begin
on a new line.

=== SLIDE 34 ===
The position Property
LAYOUT
static is normal document flow and the default for most elements.
relative stays in normal flow but can be offset.
absolute is positioned relative to its nearest positioned ancestor.
fixed stays at a fixed viewport position when scrolling.
sticky behaves normally until a scroll threshold is reached.
.label {
  position: relative;
  top: 10px;
  left: 20px;
}
EXPECTED RESULT
Label moves down 10px
and right 20px.

Position, z-index and Overflow
LAYOUT
top, right, bottom and left set offsets for positioned elements.
z-index controls stacking order when elements overlap.
overflow controls content that does not fit inside an element.
Common overflow values: visible, hidden, scroll and auto.
.popup { position: absolute; z-index: 5; }
.panel { height: 100px; overflow: auto; }

=== SLIDE 36 ===
Flexbox: One-Dimensional Layout
FLEXBOX
Flexbox arranges items along one main axis: row or column.
Start with display: flex on the parent container.
flex-direction chooses row, column, row-reverse or column-reverse.
Useful for navigation bars, toolbars and aligned cards.
.container {
  display: flex;
  flex-direction: row;
}
EXPECTED RESULT
[ Item 1 ]  [ Item 2 ]  [ Item 3 ]

=== SLIDE 37 ===
CSS Grid: Rows and Columns
CSS GRID
CSS Grid is a two-dimensional layout system.
It organises content in rows and columns.
display: grid activates Grid on a container.
grid-template-columns defines column sizes.
grid-template-rows defines row sizes.
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
}
EXPECTED RESULT
[ 1 ]  [ 2 ]  [ 3 ]
Three equal-width columns.

COMMON ELEMENTS
list-style-type changes list markers: disc, circle, square or decimal.

text-decoration: none can remove underlines from links.

Images: object-fit and object-position
IMAGES
width and height set image dimensions.
object-fit controls how the image fills its box.
cover fills the box and may crop part of the image.
contain shows the full image and may leave empty space.
object-position chooses which part remains visible.
img {
  width: 300px;
  height: 180px;
  object-fit: cover;
  object-position: center;
}
EXPECTED RESULT
Image fills a 300 × 180px box;
outer edges may be cropped.

Opacity, Transitions and Transforms
EFFECTS
opacity controls transparency: 1 is fully visible, 0 is invisible.
transition makes property changes happen smoothly over time.
transform can rotate, scale, translate or skew an element.
These effects are often combined with :hover.
button { background: navy; transition: background .4s; }
button:hover { background: green; }
.box { transform: rotate(10deg); }
EXPECTED RESULT
Button changes colour smoothly;
box is rotated.

=== SLIDE 41 ===
CSS Animation
EFFECTS
Animation changes an element's style over time.
@keyframes defines the stages of an animation.
animation-duration sets the time for one cycle.
animation-iteration-count sets how many times it runs; infinite repeats.
@keyframes move {
  from { transform: translateX(0); }
  to { transform: translateX(80px); }
}
.box { animation: move 2s infinite; }
EXPECTED RESULT
Box repeatedly moves
horizontally.

=== SLIDE 42 ===
CSS Units of Measurement
CSS UNITS
px means pixels, a fixed CSS length unit.
% is relative to a reference dimension, depending on the property.
em is relative to the element's computed font size.
rem is relative to the root element's font size.
vw and vh are percentages of viewport width and height.
.example {
  width: 50%;
  padding: 1rem;
  font-size: 2vw;
}
EXPECTED RESULT
Element takes half its containing width;
spacing uses rem.

=== SLIDE 43 ===
Responsive Design and Media Queries
RESPONSIVE DESIGN
Responsive design helps a website adapt to different screen sizes.
A media query applies CSS only when a condition is met.
max-width often applies mobile styles below a chosen width.
Test layouts on desktop, tablet and mobile.
body { background: lightblue; }
@media (max-width: 600px) {
  body { background: lightgreen; }
}
EXPECTED RESULT
Wide screen: light blue;
600px or below: light green.
