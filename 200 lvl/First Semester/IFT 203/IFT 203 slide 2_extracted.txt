=== SLIDE 4 ===
Web
The web (World Wide Web or WWW) is a system of interconnected documents and resources accessed via the internet using a web browser. It allows users to browse websites, access information, and interact with online services.
Example:
A website like www.nileuniversity.edu.ng contains multiple pages about the university, courses, and admission requirements.
=== SLIDE 5 ===
Web Page
A web page is a single document within a website that is displayed in a web browser.
A single document on the Web, written in HTML, displayed in a browser.
Example:
The homepage of www.google.com is a web page with a search bar.
https://www.cnn.com/world is a specific page on CNN’s website.
=== SLIDE 6 ===
Website
A website is a collection of web pages stored on a web server and accessible via the internet.
A collection of related web pages under a single domain name, hosted on a web server.
Example:
www.wikipedia.org – A website containing a vast amount of knowledge and articles.
www.amazon.com – An e-commerce website.
=== SLIDE 7 ===
Web Browser
A web browser is a software application used to access and view/display web pages in websites.
Examples of Web Browsers:
Google Chrome
Mozilla Firefox
Microsoft Edge
Safari (Apple Devices)

=== SLIDE 8 ===
URL
URL = Uniform/Universal Resource Locator
A URL is the address of a web page on the internet.
The address used to access a resource on the Web.
Structure:
protocol://domain-name/path 
Example:
https://sis.nileuniversity.edu.ng/pms/  is the URL for Nile University’s staff page. 
https://www.example.com/index.html
=== SLIDE 9 ===
Domain Name
A domain name is the human-readable name/address of a website.
It maps to an IP address of a server on the Internet.
It makes it easy for users to access websites without remembering numerical IP addresses.
Instead of typing 142.250.72.238 (Google’s IP), you type google.com.
Example:
google.com is the domain name for Google. 
www.facebook.com is a domain name pointing to Facebook’s server IP.
=== SLIDE 10 ===
Domain Name Structure
A domain name typically consists of two main parts:
Second-Level Domain (SLD) + Top-Level Domain (TLD)

Example: In google.com
google = Second-Level Domain (the brand name)
.com = Top-Level Domain
Subdomain     Second-Level Domain     Top-Level Domain
        www                 google                   	    .com
=== SLIDE 11 ===
Domain Name Structure
Top-Level Domain (TLD): The rightmost part of the domain name. 
Examples: .com, .org. .edu, .net, and so on.
Second-Level Domain (SLD): The main identifier of the website, usually the brand name.
Examples: google in google.com, facebook in facebook.com.
Subdomain: An optional part that comes before the SLD. 
Example: www in www.google.com 
Other subdomains can include: mail.google.com (for Gmail) or maps.google.com (for Google Maps).
Root Domain:The combination of SLD + TLD (e.g., google.com)
=== SLIDE 12 ===
Domain Name Structure
So, which one is the actual domain name?
The domain name is google.com (SLD + TLD).
www.google.com is a subdomain of google.com
www is just a subdomain commonly used to indicate the World Wide Web, but it’s optional. Today, many sites work without it (for example, typing google.com works the same as www.google.com
In Summary:
Domain Name: google.com
Subdomain: www.google.com (points to the same site in most cases).

Server/Web Server
A server is a computer that hosts websites and web applications.
A web server is a computer that stores and delivers web pages when requested by a browser.

Example:

Takes the user to the "About Us" page within the same website.
=== SLIDE 33 ===
Hyperlink
External Link:
	<a href="https://www.google.com">Visit Google</a>
Takes the user to an external website (Google).

Anchor Link (Jump to Section on Same Page):
	<a href="#contact">Go to Contact Section</a>

HTTP & HTTPS
HTTP means Hypertext Transfer Protocol
HTTPS means Hypertext Transfer Protocol Secure
It is the protocol used for communication between a web browser and a web server.
A protocol for transferring hypertext documents between a web server and client.
Example:
When you type http://example.com, your browser sends an HTTP GET request to fetch the page.
HTTPS is a secure version of HTTP that uses SSL/TLS encryption.
HTTP URL: http://example.com 
HTTPS URL: https://securebank.com
